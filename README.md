# Retroconver

## Integrantes
- David Nicolás
- Yeray Sánchez

## Descripción del Proyecto
Retroconver es una aplicación móvil Android desarrollada con una estética retro inspirada en la época dorada de Tuenti (estilo vintage de los años 2000). El objetivo es recuperar la esencia de aquellas redes sociales nostálgicas mediante un entorno minimalista, fluido y totalmente enfocado a la experiencia de usuario clásica.

## Tecnologías Base
- **Plataforma:** Android (Nativo)
- **Lenguaje:** Kotlin
- **Interfaz de usuario:** Jetpack Compose
- **Persistencia y Datos:** Room (base de datos local) y DataStore (preferencias de usuario
- **Multimedia:** Gestión y visualización de fotografías y galería personal

## Funcionalidades Principales (MVP)
1. **Perfil de Usuario:** Personalización de datos, biografía y avatar al más puro estilo clásico.
2. **Muro / Blog Principal:** Visualización de publicaciones y estados recientes de la red.
3. **Galería de Fotos:** Subida y gestión de álbumes multimedia locales.
4. **Interacción y Mensajes:** Sistema de comentarios y tablón integrado en local mediante Room.
